# ระบบรับสมัครเข้าเวรจราจร (Traffic Duty Registration System)

ระบบจัดเวรจราจรประจำวันจันทร์ - ศุกร์ พร้อมระบบตรวจสอบโควต้าสมาชิกและโควต้าเพศหญิง บันทึกข้อมูลและดึงข้อมูลผ่าน **Google Sheets** โดยตรง รองรับการทำงานออนไลน์ผ่าน **GitHub Pages** 100%

## 🌟 ฟังก์ชันและฟีเจอร์เด่น

### 1. แยกหน้าเว็บ 2 ฝั่งชัดเจน
* 🧑‍🎓 **ฝั่งผู้สมัคร (Applicant View) - `index.html`:**
  * ดูสถานะโควต้าและที่ว่างแบบเรียลไทม์
  * ลงทะเบียนเข้าเวรผ่านแบบฟอร์มอัจฉริยะ (ตรวจสอบโควต้าสูงสุดและโควต้าหญิงอัตโนมัติ)
  * ค้นหารายชื่อผู้เข้าเวร (Live Search)
  * **ดูได้อย่างเดียว (Read-Only):** ไม่มีปุ่มลบหรือแก้ไขข้อมูล เพื่อความปลอดภัย
* 👮 **ฝั่งผู้ดูแลระบบ (Admin Portal) - `admin.html`:**
  * ป้องกันด้วยระบบล็อกอินรหัสผ่าน (**รหัสผ่านเริ่มต้น: `admin1234`**)
  * **ปุ่มเปลี่ยนรหัสผ่าน:** แอดมินสามารถเปลี่ยนรหัสผ่านใหม่ได้ทันที ข้อมูลจะอัปเดตลงแท็บ `ตั้งค่าระบบ` ใน Google Sheets
  * **จัดการสมาชิก:** มีปุ่มลบ / ยกเลิกสมาชิกที่สมัครเข้ามา เมื่อลบแล้วระบบจะลบแถวออกจาก Google Sheets และปรับยอดโควต้าให้อัตโนมัติ

## 🌐 วิธีนำขึ้นใช้งานบน GitHub Pages (ออนไลน์ 24 ชม. ฟรี)

### ขั้นตอนที่ 1: ติดตั้งโค้ดลงใน Google Sheets
1. เปิด Google Sheets: [รวบรวมรายชื่อเวรจราจรบอกสมาชิกของแต่ละกลุ่มวัน](https://docs.google.com/spreadsheets/d/1boXS84v-x2c7Nf29EorwiPc7vZ07Dpzva3ASxE5JoTQ/edit)
2. ไปที่เมนู **"ส่วนขยาย" (Extensions) -> "Apps Script"**
3. คัดลอกโค้ดทั้งหมดจากไฟล์ `google-apps-script/Code.gs` ไปวางแทนที่โค้ดเดิม
4. กดปุ่ม **"บันทึก" (Save / รูปแผ่นดิสก์)**

### ขั้นตอนที่ 2: Deploy เป็น Web App
1. กดปุ่มสีน้ำเงินมุมขวาบน **"การทำให้ใช้งานได้" (Deploy) -> "รายการใหม่" (New deployment)**
2. คลิกรูปฟันเฟืองเลือกประเภท: **"เว็บแอป" (Web app)**
   * คำอธิบาย: `Traffic Duty API`
   * ดำเนินการในฐานะ: `ฉัน (Me)`
   * **ผู้มีสิทธิ์เข้าถึง: `ทุกคน (Anyone)`** *(สำคัญมาก เพื่อให้เว็บเรียกใช้งานได้)*
3. กด **"ทำให้ใช้งานได้" (Deploy)** และคัดลอก **URL ของเว็บแอป (Web App URL)** (ขึ้นต้นด้วย `https://script.google.com/macros/s/.../exec`)

### ขั้นตอนที่ 3: ใส่ Web App URL ใน config.js
เปิดไฟล์ `config.js` นำ URL ที่ได้จากขั้นตอนที่ 2 มาใส่ในช่อง `GAS_WEBAPP_URL`:
```javascript
GAS_WEBAPP_URL: 'https://script.google.com/macros/s/AKfycb.../exec'
```

### ขั้นตอนที่ 4: อัปโหลดขึ้น GitHub Repository
1. เข้าไปที่ Repository ของคุณ: [https://github.com/KTC404/-](https://github.com/KTC404/-)
2. คลิกที่ลิงก์ **"uploading an existing file"**
3. ลากไฟล์ในโฟลเดอร์นี้ทั้งหมดไปวางลงในหน้าเว็บ แล้วกด **Commit changes**
4. ไปที่ **Settings -> Pages**
   * Source: เลือก Branch `main` และโฟลเดอร์ `/ (root)`
   * กด **Save**
5. รอระบบประมวลผลประมาณ 1 นาที คุณจะได้ลิงก์เว็บไซต์ออนไลน์ทันที:
   * 🌐 **หน้าผู้สมัคร:** `https://ktc404.github.io/-/`
   * 🔐 **หน้าแอดมิน:** `https://ktc404.github.io/-/admin.html`
